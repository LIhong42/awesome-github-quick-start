| Level | Meaning |

## Featured Projects
[![Filee Offline File Format Converter](https://img.shields.io/badge/Filee_Offline_File_Format_Converter-cae9f8?style=for-the-badge)](https://github.com/KnifeLemon/Filee)

Drag and drop to convert 268 formats: images, PDF, Word, Excel, PowerPoint, HWP/HWPX, audio, video, e-books, archives, CAD drawings, 3D models and more — all done locally and offline, with no file uploads. Supports Windows / macOS / Linux, and ships a `filee` command line tool plus automatic folder conversion.

[![MangoDisk Disk Cleaner & App Uninstaller](https://img.shields.io/badge/MangoDisk_Disk_Cleaner_%26_App_Uninstaller-cae9f8?style=for-the-badge)](https://github.com/harry0703/MangoDisk)

A disk cleaner and app uninstaller supporting macOS / Windows / Linux and other operating systems. Deep Cleanup finds junk in one scan across system, application, browser, developer tool and local project build artifacts, and also comes with large file finder, duplicate file cleanup, and app uninstall. Supports both command line and graphical interface modes. Scans are read-only by default, and every deletion shows you exactly what will happen before it starts.
