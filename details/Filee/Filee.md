# Filee 离线文件格式转换器

**简体中文** | [English](Filee.en.md)

## 核心特性

- **一个手势完成**：按住修饰键拖动 → 放到格式上 → 进度环走完即完成，无需打开窗口。
- **268 种格式、17 个类别**：图片、矢量图、PDF、文档、HWP/HWPX、电子表格、演示文稿、文本与标记、数据、电子书与漫画、视频、音频、字幕、压缩包、CAD 图纸、3D 模型、字体。
- **无需 Office**：DOCX / XLSX / PPTX 由内置引擎直接读写，即使电脑上装了 Microsoft Office 或 Hancom Office，Filee 也**不会使用**它们。
- **批量并行**：1 个或 100 个文件一次完成，某个文件失败不影响其余文件，还能合并成一个 PDF 或一个 ZIP。
- **100% 本地**：不上传任何内容，离线可用，无广告、无水印、无需注册，也没有文件数量或大小限制。
- **命令行与自动化**：`filee convert`、`filee watch`，支持通配符、整个文件夹、JSON 输出与退出码，适合脚本和计划任务。
- **多语言界面**：简体中文、英语、韩语等 20 余种语言。

## 下载方式

两种方式均可，官网下载无需 VPN。

### 1. GitHub Releases

访问 <https://github.com/KnifeLemon/Filee/releases/latest> 下载对应系统的安装包。

### 2. 官网下载（无需 VPN）

访问 <https://filee.sh/zh-cn/#download> 选择对应系统的版本。官网直接托管安装包，国内访问通常更顺畅。
